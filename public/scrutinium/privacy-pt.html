Política de Privacidade

Última atualização: 2 de agosto de 2026

O Scrutinium foi criado para fornecer uma plataforma de sondagens democráticas e de estatísticas demográficas. Valorizamos a tua privacidade e somos transparentes quanto aos dados que recolhemos.

1. Recolha de Dados

Utilizamos o Firebase Authentication para gerir as contas dos utilizadores. Quando inicias sessão com Google ou Microsoft, recebemos o teu UID, nome e endereço de e-mail.

Armazenamos os teus votos, perguntas submetidas e preferências de perfil (género, faixa etária, educação, etc.) no Firebase Firestore para sincronizar a tua experiência entre dispositivos.

2. Publicidade e Consentimento

Utilizamos o Google AdMob para exibir anúncios. Para cumprir os regulamentos de privacidade (GDPR/LGPD), usamos a Google User Messaging Platform (UMP) para recolher o teu consentimento antes de mostrar anúncios personalizados.

3. Eliminação de Dados

Como eliminar os teus dados:

Podes eliminar a tua conta e todos os dados pessoais associados diretamente dentro da aplicação Scrutinium:

  1. Abre o menu da aplicação.
  2. Vai a Privacidade e Conta.
  3. Clica em Eliminar conta e dados.

Esta ação remove permanentemente o teu perfil, histórico de votação e perguntas submetidas das nossas bases de dados ativas.

4. Contacta-nos

Se tiveres alguma dúvida sobre esta política ou sobre os teus dados, contacta-nos em support@scrutinium.app.
